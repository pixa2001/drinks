# Taberna Flamenca · La Carta
Mobile Getränkekarte im Latino-Boho-Stil, ohne Build-Schritt und ohne Backend.

Öffentliche Karte: https://pixa2001.github.io/drinks/

## Inhalte bearbeiten
Getränke, Preise und Kategorien stehen in `menu.js`. Design in `boho.css`, Grundlayout in `index.html`. Kategorien folgen untereinander, die Navigation springt direkt zum Abschnitt. Überschriften reagieren auf die Scrollrichtung. Reduzierte Bewegung wird berücksichtigt.

## QR-Code
`qr.svg` verlinkt auf die öffentliche Karte und kann für Drucksachen verwendet werden. Bei einer Änderung der Adresse muss der QR-Code neu erstellt werden.

## Veröffentlichung
GitHub Pages veröffentlicht den Hauptbranch aus dem Repository-Stamm. Änderungen an `main` werden automatisch veröffentlicht.

## Quellen
Getränke und Preise wurden aus der vom Betreiber bereitgestellten Karte übertragen. Logo, Boho-Grafiken und lokale Schriften stammen aus dessen Repository `pixa2001/Musicrequest`. Schriftlizenzen liegen unter `assets/fonts`.

Die Vorlage enthält eine Zusatzstofflegende ohne vollständige Zuordnung zu den Getränken; Gäste werden dazu an das Team verwiesen. Mengenangaben wurden nur übernommen, soweit sie in der Vorlage stehen.
